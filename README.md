## About

This project implements **THC3**, a toy hashing algorithm designed for learning and experimentation. It’s not suitable for security-critical applications, but it’s a fun way to explore how hashing concepts work in Python.

---

## Features

- Pure Python implementation—no external dependencies  
- Simple API for hashing strings or binary data  
- Educational focus: straightforward, easy-to-follow code
